## 🚀 About the Project
**AI-Driven Farmers** is an intelligent agricultural automation system built for the **Soft Computing (SC07)** project guidelines. The project integrates **Fuzzy Logic** to handle imprecise environmental variables (like soil moisture and ambient temperature) and **Artificial Neural Networks (ANN)** to predict optimal irrigation patterns and water requirements dynamically. 

By merging soft computing paradigms with modern automation, the system minimizes water wastage, maximizes crop yield, and operates autonomously based on real-time data inputs.

## ⚙️ Core Architecture & Tech Stack

* **Soft Computing Framework:** 
  * *Fuzzy Inference System (FIS):* Evaluates crisp inputs (soil moisture, humidity, temperature) to generate fuzzy control decisions for valve actuation.
  * *Artificial Neural Network (ANN):* Trained on historical weather and soil datasets to forecast irrigation schedules and soil water retention capacity.
* **Backend & Simulation:** Python, NumPy, Scikit-Fuzzy, Flask
* **Version Control:** Git & GitHub
